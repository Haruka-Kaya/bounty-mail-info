Bounty Mail Realtime

プライバシーポリシー

更新日: 2026年10月20日

利用目的と取得する情報

開発者本人が許可したGmailアカウントの新着履歴・メッセージID・送信元・件名・本文・ラベルを取得し、バグバウンティ関連のメールを分類します。添付ファイルは取得しません。Gmailで行う変更はラベルの追加・削除と、それによるアーカイブです。

外部サービスでの処理

処理は開発者のGoogle Cloudで実行します。認証情報はSecret Managerで、分類結果・変更前後のラベル・処理状態は専用Firestoreデータベースで管理します。Firestoreには件名や本文を保存しません。

AI判定が必要な対象メールについては、送信元ドメイン、整形した件名、本文をOpenAI Decisions APIへ送信します。リンク、メールアドレス、長い識別子、コードブロック、過去の引用をパターンにより除きますが、機密情報の完全な除去を保証するものではありません。入力上限を超える場合はAI判定を行いません。

OpenAI APIのデータは、明示的なオプトインを行わない限りモデルの学習に使用されません。本アプリは学習用のデータ共有を行いません。Decisions API自体にアプリケーション状態の保存はありませんが、標準では不正利用監視ログが最長30日間保持されます。法令やサービス保護のため延長される場合があります。Zero Data Retentionは対象者による別途承認が必要で、本アプリでは有効と見なしていません。詳細はOpenAI APIのデータ管理をご確認ください。

利用の制限

データを販売したり、広告配信に使用したりしません。開発者本人のメール整理を提供する目的に限って使用します。Bounty Mail RealtimeによるGoogle APIから受け取った情報の利用と他サービスへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

保持・停止・削除

認証情報と処理記録は、運用中は開発者の管理下で保持します。自動削除の期限は設定していません。Googleアカウントの接続管理画面から権限を取り消すと、以後のGmailアクセスを停止できます。停止時には開発者がCloud上の認証情報・処理記録の削除を管理します。
